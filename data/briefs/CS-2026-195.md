# CS-2026-195 — Suppress Watermelon Lime 6-Pack across can sections & product selectors

**Owner:** Katie Spaller  **Department:** DTC-website  **Platforms:** shopify
**Status:** approved  **Risk:** low  **Created:** 2026-06-08  **Source:** manual
**Approved by:** Katie Spaller  **Branch:** `feature/wml-6-pack-supression` (drinkkenetik/kenetik-shopify-theme)

## §10a — Hypothesis

Suppressing the Watermelon Lime / 6 Pack variant combo everywhere it surfaces — can PDP flavor/size selectors and storefront product selectors/grids — prevents customers from selecting or adding an SKU we are pulling, avoiding mis-orders and Sold-Out friction, while keeping all other flavors and the WML 12-pack fully available.

## §10b — Resolution Path (Diagnose / Remove / Refine / Add)

- **Diagnose:** Audited all sections surfacing can flavor/size. Three suppression mechanisms in the theme: (1) JS `disabledVariantsByFlavor` map on PDP-style can sections; (2) Liquid per-variant filtering in grids/selectors (`actual-variantss`, partner dropdown, `suppressed_ids`); (3) the generic `product-variant-options` snippet renders each option independently (no flavor+size combo logic).
- **Remove:** n/a — no redundant mechanism to retire.
- **Refine:** Reused each section's existing suppression pattern rather than introducing a new one — extended the JS map and the existing flavor-skip loops.
- **Add:** Only net-new code is the client-side combo-hide in `product-variant-options.liquid`, required because that snippet renders options independently; it no-ops on any product lacking both a Watermelon Lime flavor and a 6 Pack size.

## §10c — Scope (approved by Katie)

JS `disabledVariantsByFlavor` map (`'watermelon-lime': ['6-pack']`):
- `sections/KS-can-product-section.liquid`
- `sections/KS-can-protocol-section.liquid`
- `sections/cw-01-product-banner.liquid`

Liquid variant filtering:
- `snippets/product-variant-options.liquid` — powers product / section-product / api-product-quickview; client-side combo hide via `data-select-label` hooks
- `sections/hp-product-grid.liquid` — skip in `actual-variantss`
- `sections/KS-best-sellers.liquid` — skip in both `actual-variantss` loops
- `sections/KS-partner-products.liquid` — skip in count + dropdown loops

Excluded per scope review: shot sections, `ks-subscription-product`, `KS-partner-subscription`/`KS-partner-sticky-bar` (config-driven single variant), and card/popdown sections (no variant selection).
