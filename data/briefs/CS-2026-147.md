## Hypothesis

Site-wide CVR halving (Mobile -33.5%, Desktop -58.4%, Tablet -77.1%) coincides with 31.6% of LP sessions falling into (not set)/(empty) buckets and Clarity reporting 100% of URLs as low_confidence. Hypothesis: a tracking-instrumentation regression (GA4 collection / Shopify theme push / referrer-policy / Cloudflare WAF / pixel mis-fire) is the common root cause and is producing CVR symptoms across every device. Removing the broken script will recover most of the apparent CVR loss; LP redesign work is downstream of the diagnostic.

## §10a Hypothesis (expanded)

A site-wide CVR collapse appearing on the same day across all three device classes (Mobile -33.5%, Desktop -58.4%, Tablet -77.1%) with sessions UP +38.3% and 31.6% of landing-page sessions in `(not set)`/`(empty)` GA4 buckets is structurally inconsistent with a CRO regression. CRO regressions are usually device-specific and traffic-flat or traffic-down. A common root cause that produces the observed pattern is a tracking-instrumentation regression: a Shopify theme push that broke `gtag('event','page_view')` firing, a referrer-policy meta change stripping UTM, a Cloudflare WAF rule blocking analytics calls, or a pixel mis-fire that records sessions but not conversions. Clarity confirms code-level breakage (script_errors 234/1k on `/vs-other-ketones`) and reports 100% of URLs as low_confidence — the script-error footprint is consistent with a global breakage, not a single-LP issue.

## §10b Resolution Path

- **Diagnose:** Pull last 7d theme deploy log + GA4 conversion-event daily curve + ad-platform spend deltas 4/30–5/6 + referrer-policy/UTM regression scan. Decision tree: regression in pixel/GA4 → Peter; traffic-mix → D04 paid-media RCA; theme/global element → Katie rolls back.
- **Remove:** If broken script identified, REMOVE before refining anything else (Clarity script_errors 234/1k on `/vs-other-ketones` is the highest-confidence single signal).
- **Refine:** Once tracking restored, re-evaluate CS-2026-138 LP scope; the redesign argument may shrink substantially once attribution is clean.
- **Add:** Add a tracking-regression triage section to `brain/kenetik-brain/playbooks/website-cvr-diagnosis.md` so the next site-wide CVR drop with sessions UP routes to instrumentation diagnostic by default (LEARNING SIGNAL captured in synthesis 2026-05-07-s1).
