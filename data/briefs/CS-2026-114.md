## Hypothesis
When a visitor toggles to a flavor that doesn't offer their previously-selected pack size (e.g. **6-Pack** on Original Variety → **Strawberry Peach**), the old size is unchecked but no replacement pack size is auto-selected, leaving the Add-to-Cart form in an invalid state. Auto-selecting the first visible pack size on every flavor change will eliminate this dead-end and recover confused-visitor conversions.

## Change
Patch `sections/cw-01-product-banner.liquid` (single file, +25 / -0):

- Add `autoSelectFirstAvailableSize()` helper inside the section's `DOMContentLoaded` block. It:
  1. Collects all `.size-option` elements
  2. Filters to those currently visible (`style.display !== 'none'`)
  3. If none of the visible options have a checked input, checks the first visible + enabled option
  4. Dispatches a bubbling `change` event so the existing price / variant-select / flavor-slider listeners fire
- Call `autoSelectFirstAvailableSize()` inside the `.flavor-selector` change handler (after `updateSizeOptions` + `updateDisabledVariants`) and in the initial setup block (when `initialFlavor` exists).
