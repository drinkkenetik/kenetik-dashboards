## Problem
Blended site CVR is +21% WoW, but the desktop funnel is hiding a severe regression: **Desktop CVR -15.7% WoW** with component-level collapse on three surfaces:

| Surface | Desktop CVR delta (WoW) | Role |
|---|---|---|
| Homepage | **-44%** | Primary entry |
| Shots PDP | **-71%** | Top-revenue SKU |
| Concentrate PDP | **-28%** | Secondary SKU |

Mobile CVR is flat-to-positive across the same surfaces, which localizes the regression to a **desktop-rendered component** (layout shift, hero block, PDP sticky-ATC, or theme variant published to desktop-only). The magnitude (-71% on the highest-margin SKU) means we're bleeding ~$2.3–3.1k/day while running at a confirmed Google Ads 9.16x ROAS streak — paid is throwing demand at a broken funnel.

## Resolution Path

## Approach

### Phase 1: Diagnose (48h)
1. **Shopify theme diff** — pull theme version history for the last 14 days; identify desktop-specific component publishes (theme customizer, section schema, hero block edits)
2. **Polar session replay** — 20 desktop sessions per surface (Homepage, Shots PDP, Concentrate PDP); flag rage-clicks, dead-clicks, viewport anomalies
3. **GA4 desktop vs mobile funnel** — ATC rate, begin_checkout rate, purchase rate by device × page_type (re-use CS-056 methodology)
4. **Core Web Vitals pull** — LCP/CLS/FID for desktop vs mobile across the three surfaces (last 14d); a desktop-only CLS regression is a top suspect

### Phase 2: Remove / Refine (48h after diagnosis)
- **If theme component identified:** Roll back to last-known-good theme version (low risk, standard Shopify rollback)
- **If CWV regression:** File engineering ticket with specific LCP/CLS/FID delta and root cause
- **If not isolable within 48h:** Escalate to Devon for CS-096-tier engineering investigation
