## Problem Statement

The current Shopify theme has two PDP/shop section patterns, neither of which fits a single-bundle product with subscription:

- `ks-gp-shop.liquid` (Golden Pear LE Shop) — purpose-built for the Golden Pear LE drop. Assumes multiple variant packs (6 / 12 / 24) and includes drop-specific UX (hunt-stamp overlay, cans-found counter, "what's in the can" ingredient panel). No subscription option.
- `cw-01-product-banner.liquid` — generic PDP with variant pickers and a Recharge subscription box, but assumes multi-flavor / multi-pack variants and uses page-context `product` rather than a theme-editor product picker.

Neither section supports the new use case: a single-bundle product (no variants) with one-time vs. Subscribe & Save purchase options, drop-in-able on any page.

## Proposed Solution

Build a new Shopify theme section, `ks-subscription-product.liquid`, that:

1. **Reuses the GP Shop visual layout** — two-column shop layout, eyebrow / H2 / sub, star rating row, trust strip, sticky mobile ATC bar, gradient ATC button, JSON-LD product schema.
2. **Drops the variant pack-picker, ingredient panel, and hunt-stamp overlay** (not relevant for a single-bundle product).
3. **Ports the cw-01 purchase-type box** — radio group with `one-time` / `subscribe-save`, plus a Recharge selling-plan dropdown that's enabled only when Subscribe & Save is selected. Auto-calculated "Save X%" badge from the price delta.
4. **Adds a new JS asset** (`ks-subscription-product.js`) handling: quantity stepper with per-customer limit, purchase-type toggle, selling-plan change, live total recalculation, sticky ATC sync, and `/cart/add.js` form submit (passing `id`, `quantity`, `selling_plan`).
5. **Loads cw-product-banner.css + cw-subscription.css** alongside the existing ks-golden-pear-lp.css so the purchase-type box inherits the standard subscription styling while the shop chrome stays consistent with GP Shop.

All customer-facing copy is editable via theme-editor settings (eyebrow, H2, sub, trust strip × 3, purchase-type labels, footnote, etc.). The bundle product is selected via a `product` schema picker, so the section can be dropped on any page.
