## 1. Summary

Deploy a Shopify Flow automation that writes `acquisition_source` and `referring_creator` custom properties to Klaviyo customer profiles when a Superfiliate-attributed order is created, enabling profile-level segmentation and flow routing for creator-acquired customers.

## 2. Objective

**Optimization Hierarchy Level:** L3 — Customer Quality / LTV + L4 — Rate of Learning
**Department:** DTC-website
**Platforms:** [shopify]

This ChangeSet closes the attribution gap identified by CS-2026-010. Today, the only way to identify Superfiliate-acquired customers in Klaviyo is by matching discount codes on Placed Order events — a fragile, incomplete workaround that misses code-less conversions and cannot be used for profile-level segmentation or flow conditional splits. By writing a persistent profile property, we unlock:

- Superfiliate-specific welcome flows (building on CS-2026-001)
- Per-creator cohort retention campaigns (building on CS-2026-007)
- Accurate creator ROI attribution in Klaviyo (feeding CS-2026-004 Polar integration)
- Any future flow or segment that needs to know "was this customer acquired via a creator?"

## 6. Payload — Before (Current State)

- No profile-level Superfiliate attribution on customer profiles in Klaviyo
- Superfiliate order tag `superfiliate conversion approved` exists on Shopify orders but doesn't propagate to Klaviyo
- Only attribution method: discount code matching on Placed Order events (incomplete, manual)
- Broken segment "Influencer-Acquired - All Creators" (U22Pai) uses `$source contains superfiliate` which returns incorrect results

## 7. Payload — After (Target State)

### New Klaviyo Custom Profile Properties

| Property | Type | Value | Set By |
|---|---|---|---|
| `acquisition_source` | String | `"superfiliate"` | Shopify Flow on order creation |
| `referring_creator` | String | Creator code from discount (e.g., `"cleetus"`, `"roman"`) | Shopify Flow on order creation |
| `superfiliate_first_order_date` | Date | Order creation date | Shopify Flow on order creation (only set if property is currently empty — don't overwrite on repeat purchases) |

### Shopify Flow Design

1. **Trigger:** Order created
2. **Condition:** Order tags contain `superfiliate conversion approved`
3. **Action 1:** Extract discount code from order (lowercase, trim)
4. **Action 2:** Call Klaviyo API (or use Klaviyo Shopify connector "Update Profile Properties"):
   - Set `acquisition_source` = `"superfiliate"`
   - Set `referring_creator` = extracted discount code
   - Set `superfiliate_first_order_date` = order created date (only if null)

### Retroactive Backfill

After Flow is live, run a one-time backfill script:
1. Query Shopify for all orders tagged `superfiliate conversion approved`
2. For each order, extract customer email + discount code
3. Batch update Klaviyo profiles via API

### Segment Updates

After properties are populated:
1. **Fix** segment U22Pai ("Influencer-Acquired - All Creators"): Change definition from `$source contains superfiliate` to `acquisition_source equals superfiliate`
2. **Create** per-creator segments where needed (e.g., `referring_creator equals cleetus`)
