## Hypothesis

Desktop Add-to-Cart rate has dropped -29.1% while mobile ATC is down only -11.6%, suggesting a cart-level infrastructure issue rather than a traffic quality problem. Mobile CVR is simultaneously up +32.9%, confirming the funnel divergence is device-specific. The cart path on desktop has a structural break that is suppressing conversion independently of traffic or creative performance.

Candidate root causes (priority order): (a) Shopify theme deploy affecting desktop cart rendering, (b) checkout script conflict on desktop browsers, (c) third-party app (ReCharge, Elevar, or loyalty widget) injecting desktop-specific JS errors, (d) page speed regression on desktop cart pages, (e) A/B test or personalization rule misfiring on desktop.

## Baseline Data (2026-04-16)

- Desktop ATC rate: -29.1% WoW (dept-website-cro.md)
- Mobile ATC rate: -11.6% WoW
- Mobile CVR: +32.9% WoW
- Organic clicks: -36.9% WoW (may be correlated or independent)
- New customer orders: -24.4% WoW (downstream impact)

## Actions

1. Pull Polar Analytics device-level funnel data (sessions > PDP > ATC > checkout > purchase) for desktop vs mobile, daily for the last 14 days.
2. Audit Shopify theme deploy log for changes between 4/7 and 4/14 (the WoW comparison window).
3. Run Chrome DevTools audit on desktop cart page -- check for JS errors, blocked resources, layout shifts.
4. Check ReCharge, Elevar, and loyalty widget versions for desktop-specific updates.
5. If root cause found: draft implementation CS for fix. If not found within 48h: escalate to Devon for engineering resource allocation.

## Success Criteria
