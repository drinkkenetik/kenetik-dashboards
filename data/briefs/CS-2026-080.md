## Hypothesis

Adding a transparent-background variant of the existing `cw-sweeps-bundle` Shopify theme section — with the chances counter removed and the body/image columns swapped — to Cleetus' Pit Crew Koozie landing page will let the bundle feature the Cleetus Pit Crew Bundle (Variety 12-Pack + Pit Crew Koozie at $59.88, koozie free with the 12-pack [src: data/marketing-calendar/marketing-calendar-data.json#ARCA-KAN-041726-BEAT-03]) in a clean, non-sweepstakes layout that matches the lander's existing Cleetus creative treatment, without regressing the live Leadville sweeps page that relies on the original section's defaults.

## Resolution Path: **Add**

Why this path: Refining the existing `cw-sweeps-bundle.liquid` section with conditional toggles would mean every future render of the Leadville sweeps lander rides on logic that didn't exist before — a regression surface we'd have to test every time the section is edited. Removal is not applicable (the original section must stay intact for Leadville). Adding a parallel section variant (`cw-sweeps-bundle-transparent.liquid`) isolates the Cleetus-specific presentation, reuses the existing `cw-sweeps-bundle` BEM classes and responsive CSS by reference, and is trivially reversible by deleting the file and removing the block from the lander.

- **Diagnose:** Lander needs a product bundle block that is visually lighter (transparent background), skips sweepstakes framing (no chances counter), and leads with product copy on the left for the Cleetus lander's creative direction. Today the only equivalent section is the Leadville sweepstakes variant which is dark-themed, sweeps-branded, and copy-right.
- **Remove considered:** No — nothing to remove; the lander currently has no bundle module to replace.
- **Refine considered:** Yes — could add toggles to `cw-sweeps-bundle.liquid`. Rejected because it couples the live Leadville sweeps page to every future Cleetus-driven edit and inflates the schema for one-off visual needs.
- **Add chosen:** New section file `sections/cw-sweeps-bundle-transparent.liquid` with schema name "Sweeps Bundle Transparent". Reuses shared `cw-sweeps-bundle__*` CSS classes so cards, typography, and responsive stacking behave identically.

## Change

- **Before:** Cleetus Pit Crew Koozie landing page does not include a bundle module. The only bundle section available in the theme (`sections/cw-sweeps-bundle.liquid`) is dark-themed (`background: #000`), renders a "= X Chances" entries badge, and places the product image on the left with copy on the right [src: drinkkenetik/kenetik-shopify-theme/sections/cw-sweeps-bundle.liquid].
- **After:** New section file `sections/cw-sweeps-bundle-transparent.liquid` (schema name "Sweeps Bundle Transparent") committed on branch `sweeps-bundle-transparent` in `drinkkenetik/kenetik-shopify-theme` (commit `3ebc719`). Differences vs. original: (1) scoped inline `<style>` sets `background: transparent` and adjusts text colors for legibility on light backgrounds; (2) entries badge and `entries_per_dollar` schema setting removed; (3) HTML order inside `.cw-sweeps-bundle__card` swapped so `.cw-sweeps-bundle__card-body` renders before `.cw-sweeps-bundle__card-img` in both the connected-product and fallback render paths (swaps left/right in the `1fr 1fr` grid, stacks body-above-image on mobile). Section ID is namespaced with `section.id` so multiple instances do not collide. Reuses all `cw-sweeps-bundle__*` CSS from `assets/cw-leadville-sweepstakes.css` by reference. Add the new section to the Cleetus Pit Crew Koozie lander template via the theme editor, connect it to the Cleetus Pit Crew Bundle product, and set CTA copy.
