# CS-2026-218 — Wholesale theme home · fix CTA/footer/cart text contrast, hero image, header height

**Department:** DTC-website · **Platforms:** shopify · **Status:** draft · **Owner:** Katie Spaller · **Risk:** low · **Autonomy tier:** 0 · **Review tier:** express · **Source:** manual · **Created:** 2026-06-29

## Summary
Four legibility/display bugs plus an over-tall header on the wholesale storefront home page (`drinkkenetik/wholesale-shopify-theme`). Minimal, additive fixes on a branch off the known-good `main`; the human opens/merges the PR (api.github.com blocked in sandbox). Related to CS-2026-217 (the wholesale site rebuild).

## Root cause
A single site-wide rule in `assets/ks-wholesale-global.css` — `a:not(.button):not(.ks-btn) { color: var(--ks-blackberry); }` — forced navy on every link. That made the cart-drawer checkout text (navy-on-navy) and the footer "Need help?" email (navy-on-black) invisible. The remaining issues were local: weak text-shadow on the warm-gradient hero button, the hero image bound via a CSS variable on the section that wasn't taking effect, and an unconstrained logo `<img>` + stretching CTA inflating header height.

## Resolution Path (Diagnose / Remove / Refine / Add)
- **Diagnose:** Re-derived all edits from `main`; confirmed the global link rule as the shared root cause of the invisible cart-checkout + footer-email text.
- **Remove:** Deleted the global `a:not(.button):not(.ks-btn)` navy link rule; removed the `--hero-bg-desktop` CSS-variable-on-the-section approach in the hero.
- **Refine:** Strengthened `.btn-primary` text-shadow (`0 1px 2px/0.18` → `0 1px 3px/0.45`); cart checkout `var(--ksw-navy,#0e4f5e)`→`#13296e` with `color:#fff !important`; hard-capped logo img to 36px and made `.ks-wholesale-header__cta` non-stretching; fallback wordmark → "Kenetik Wholesale".
- **Add:** `.ks-wholesale-footer__help a { color:#fff; }`; inline `background-image` directly on `.hero-bg`.
