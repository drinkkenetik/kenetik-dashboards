### Claims-language guardrails (carry into Brief A approval)

The new paper is observational + cross-sectional. Brief A copy must:

- Use **"associated with"** language, not **"causes"** or **"reduces."** *"Higher BHB levels were associated with a more favorable metabolic profile in 269,178 UK Biobank participants"* is allowable. *"BHB reduces metabolic syndrome"* is not.
- The β-HB threshold studied is **mild ketosis (≥0.12 mM)**, which is below the elevated levels Kenetik produces. Frame as *"even mild elevations in ketones are associated with..."* — directionally honest, doesn't overclaim Kenetik dose-response.
- The MetS finding is **metabolic profile**, not cognitive. If Brief A bridges to cognitive claims, it does so via a separate citation (Frontiers meta from Brief B), not by extending Park & Choi.
- Polygenic-risk-score finding is interesting but **must not** become a personalized-medicine framing for consumer copy ("ketones work better for some people genetically") — that crosses into territory the matrix doesn't permit.

### L-(new) — Day-prior publication blind spot — codify the process

The synthesis flagged a real process gap even if this specific case was a no-op: D16 should run a publication-supersession check against active CS family briefs **before** any claims-approval routes. Concretely:

1. On every D16 scan, compare the new-publication list to citation anchors in `status ∈ {draft, approved}` CSes via `references_consulted[]` parsing.
2. If any new paper is in the same parent dataset / same domain / larger N than an anchor, surface a **supersession candidate** flag — not a halt, but a one-line nudge in the synthesis.
3. Today's run would have produced *zero* supersession candidates because Brief A was already on the new paper. The check is a guard, not a frequent fire.
