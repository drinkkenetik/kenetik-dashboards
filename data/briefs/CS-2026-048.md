**Status:** CLOSED (2026-04-22) — outcome: `superseded`

## Closure — 2026-04-22 (Katie)

**Why closed:** False-positive graduation flag. The TikTok post (video ID `7622720005091740941`, published 2026-03-29) was already running in Kenetik paid rotation on 2026-04-06 when Moe's weekly graduation scan flagged it as a graduation candidate. The scan didn't cross-check against currently-live paid creatives before recommending, so it produced a duplicate ask. There was never any new paid amplification to do — the work this CS proposed was already happening, attributable to the original (pre-existing) campaign, not to this CS.

**Actual impact:** $0 attributable to this CS. The underlying video's existing paid performance is tracked under its original campaign's `ad_platform_refs`, not here. Draft sat for 16 days before the duplication was caught.

**Meta-learning (for the graduation pipeline):**

Moe's weekly graduation-scan command must dedupe against currently-live paid creatives before recommending a candidate. Without that step, organic posts whose content is already running paid get re-flagged as graduation opportunities, burning review capacity, cluttering the draft queue, and delaying triage of genuinely novel candidates.

**Forward application — for Moe's weekly graduation scan and the graduation pipeline:**

1. Before emitting a graduation candidate, the scan must query `paid-media-state.json` (or equivalent live paid creative inventory) and exclude any organic post whose source content already has an active `ad_platform_refs` entry.
2. Matching logic should compare on (a) platform post URL or video ID, and (b) creative hash / filename / caption similarity for cases where the same creative is uploaded natively to the ad platform rather than dark-posted from the organic handle.
3. If a partial match is found (e.g., similar creative but different platform), the scan should flag it as "candidate — partial overlap with live paid, review" rather than a clean graduation recommendation.
4. The `graduation-pipeline-management` and `pull-metrics` skill files should surface the dedupe gap as a known issue until the fix ships, so operators reviewing graduation drafts know to spot-check "is this already running paid?" before approving.

**Reusable signal:** The Ashton Hall "longevity > hype" framing did perform (5.7% TT engagement) and is already in paid rotation — this CS closing doesn't remove or roll back any of that. If further amplification is desired on a different angle or audience, that would be a new CS, not a re-open of this one.
