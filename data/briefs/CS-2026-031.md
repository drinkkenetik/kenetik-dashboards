## Problem Statement

Domain 02 (Session 14) flagged that a majority of Klaviyo flow emails were generating zero clicks. The original brief stated "121 of 217 active Klaviyo flows" — but a direct Klaviyo API audit on Mar 23 revealed this was **mischaracterized**:

- The "217" (later 226/227) figure counts **individual flow email messages**, not flows
- Kenetik has **28 unique flows** containing 227 email messages total
- Of 119 zero-click messages, **106 had fewer than 50 recipients** (deep-in-sequence messages that are not statistically significant)
- Only **13 zero-click messages** had 50+ recipients; only **2** had 100+ recipients

The real problem is not zero-click messages — it's **high-volume messages with extremely low click rates (<1%)**. There are 45 flow emails with 100+ recipients and sub-1% CTR, including emails reaching 4,000-5,000 people per month.

## Hypothesis (Revised)

Redesigning CTA elements across the top ~15 highest-volume, lowest-CTR flow emails will recover measurable click-through rates and flow-attributed revenue. This is a more targeted, higher-impact approach than the original "fix 121 flows" scope.

## Resolution Path (added 2026-04-22)

| Step | Considered? | Result |
|---|---|---|
| Diagnose | Yes | Root cause hypothesis: high-volume flow messages have CTAs that fail to drive clicks — low-contrast buttons, below-fold placement, weak urgency/benefit copy, indirect product links. Corroborating: 18 Tier-1 messages (≥1K recipients, sub-1% CTR) span 5 flow families — consistent failure mode across flows points to creative-design issue, not audience or send-time [src: cgo-logs/changesets/CS-2026-031.md#priority-tier-1]. Fresh 2026-04-22 scan confirms pattern persists: Expected to Purchase 0.34% CTR, Customer Winback 0.82%, Welcome Series 0.58%, Browse Abandonment 0.98% — same flows, same problem, 30 days later [src: cgo-logs/domain-scans/2026-04-22-s1/domain-02-brief.md#flow-performance]. |
| Remove | Yes | Considered removing the lowest-performing messages from their flows entirely (e.g., drop Expected to Purchase Email #3 with 0.20% CTR). Rejected — these messages fire on triggered states (new subscriber, free-pack recipient, checkout abandoner) where we want SOME touchpoint. Removing is the "don't re-engage these customers at all" option, which is worse than redesigned messaging. |
| Refine | Yes | Considered directly modifying the CTAs on existing messages (in-place edit, no A/B). Rejected — direct modification loses causal attribution (can't tell if any lift is from CTA change, seasonal, audience mix, or noise). Also risks regression: if new design underperforms, there's no safe baseline running. Direct Refine works for single-message edits; for a 15-message campaign-wide design shift, A/B structure is required for credible learning. |
| Add | Yes | **Chosen path.** Create A/B variant pairs for each Tier-1 message: variant A = current message (control, unchanged), variant B = redesigned CTA (treatment). Klaviyo flow A/B infrastructure handles the 50/50 split and attribution per message. New complexity = 15 A/B configurations, but each is a standard Klaviyo flow A/B. Complexity is justified by: (a) clean causal measurement, (b) automatic rollback (remove variant B if it loses), (c) per-message winner selection (not all messages respond the same), (d) extractable pattern for future CTA design (L4 learning). |

Resolution Path: **Add** — A/B variant pairs alongside existing messages. Each test is reversible (remove variant B = original only). Scale winners; discard losers.

**Action + Condition pair:** For each of the 15 Tier-1 messages, run an A/B variant test for 14 days. Decision per message: **if variant B CTR ≥2.0% AND ≥50% relative lift over variant A AND N≥1,000 recipients with p<0.05 → scale variant B (set as primary, retire variant A); if variant B ≤ variant A OR no statistical significance after 14 days → remove variant B, variant A continues unchanged.**

**Depth-escalation waiver:** No /rca trigger fires unambiguously. Multiple candidate causes exist (CTA design vs audience vs content relevance), but the A/B test structure IS the disambiguation mechanism — if CTA redesign is the right lever, variants will lift; if not, we've learned the problem is elsewhere (which itself is a valuable signal pointing to next investigation: audience segmentation or trigger timing). One-line waiver per §10b: shallow diagnosis sufficient because the Add-A/B structure internalizes causal disambiguation.
